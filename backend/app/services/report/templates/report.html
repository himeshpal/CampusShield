How to read this report. Every device gets a risk score from 0 to 100, computed by a documented rule set from what the network scan found (exposed services, known vulnerabilities, unexpected ports), the manual security checklist and whether the device is registered. The total is weighted by how critical the device is to the campus. Bands: Low below 25, Medium 25-49, High 50-74, Critical 75 and above. Section {{ num.method }} lists every rule.

This is a point-in-time snapshot taken {{ r.generated_at | local }}. Later scans and checklist updates are not reflected; generate a new report from CampusShield for the current state.
